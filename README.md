# SephPlanner

세피리아(Sephiria)용 비공식 석판 배치 도우미입니다. 가방을 읽어 석판을 어디에 놓으면 좋을지
계산해서 게임 화면 안에 보여 주고, 싱글플레이에서는 F8 한 번으로 그 배치대로 옮겨 줍니다.
멀티플레이에서는 보여 주기만 합니다.

TEAM HORAY와 무관한 팬 제작 도구이며 무료입니다. 싱글플레이 자동 배치는 개발사에 확인을
받았습니다.

## 받기

[Releases](https://github.com/nyattic/SephPlanner-Release/releases)에서 최신 zip을 받으세요.
설치 방법은 zip 안의 `설치안내.txt`에 있습니다. BepInEx는 따로 설치해야 하며, 게임 파일은
들어 있지 않습니다.

## 문제가 있을 때

[Issues](https://github.com/nyattic/SephPlanner-Release/issues)에 올려 주세요. `설치안내.txt`의
"문제가 있을 때"에 적힌 파일 두 개를 함께 올려 주시면 빨리 확인할 수 있습니다.

게임 자체가 이상하다면 먼저 이 도구를 지워 보세요. 지운 뒤에도 같은 문제가 나면 게임 쪽
문제이므로 TEAM HORAY에 알려 주시는 것이 맞습니다. 개발사가 모드 문제와 게임 문제를 구분할
수 있도록 부탁한 내용입니다.

## 이 저장소에 대해

배포용 저장소입니다. 소스 코드는 공개하지 않으며, 여기에는 zip만 올립니다.
사용 조건은 zip 안의 `LICENSE.txt`에 있습니다. 개인적·비상업적 사용은 자유이고, 재배포와 수정은
허용하지 않습니다.
