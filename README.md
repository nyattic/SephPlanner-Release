# SephPlanner

세피리아(Sephiria)용 비공식 석판 배치 도우미. 가방을 읽어 석판을 어디에 놓을지 계산해서
게임 화면 안에 바로 보여 주고, 싱글플레이에서는 F8 한 번으로 그 배치대로 옮겨 준다.
멀티플레이에서는 보여 주기만 한다.

TEAM HORAY와 무관한 팬 제작 도구이며 무료다. 싱글플레이 자동 배치는 개발사에 확인받았다.

## 받기

[Releases](https://github.com/nyattic/SephPlanner-Release/releases)에서 최신 zip을 받는다.
설치 방법은 zip 안의 `설치안내.txt`에 있다. BepInEx는 따로 설치해야 하고, 게임 파일은 들어 있지 않다.

## 제보

[Issues](https://github.com/nyattic/SephPlanner-Release/issues)에 올려 달라. `설치안내.txt`의
"문제가 있을 때"에 적힌 파일 두 개를 같이 올리면 빠르다.

게임 자체가 이상하면 먼저 이 도구를 지워 보고, 지운 뒤에도 같으면 그건 게임 문제니 TEAM HORAY에
알리는 것이 맞다. 개발사가 모드 문제와 게임 문제를 가려낼 수 있게 부탁한 내용이다.

## 이 저장소

배포용이다. 소스 코드는 공개하지 않으며, 여기에는 zip과 변경 기록만 둔다.
사용 조건은 zip 안의 `LICENSE.txt`에 있다. 개인적·비상업적 사용은 자유이고, 재배포와 수정은 안 된다.
